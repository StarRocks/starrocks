
##### enable_auth_check

- Default: true
- Type: Boolean
- Unit: -
- Is mutable: No
- Description: Specifies whether to enable the authentication check feature. Valid values: `TRUE` and `FALSE`. `TRUE` specifies to enable this feature, and `FALSE` specifies to disable this feature.
- Introduced in: -

##### warehouse_idle_check_enable

- Default: true
- Type: Boolean
- Unit: -
- Is mutable: Yes
- Description: Specifies whether to enable WarehouseIdleChecker. When this feature is enabled, you can check the idle status of the cluster.
- Introduced in: v3.3
