# session_variables

`session_variables` provides information about session variables.

The following fields are provided in `session_variables`:

| **Field**      | **Description**        |
| -------------- | ---------------------- |
| VARIABLE_NAME  | Name of the variable.  |
| VARIABLE_VALUE | Value of the variable. |
