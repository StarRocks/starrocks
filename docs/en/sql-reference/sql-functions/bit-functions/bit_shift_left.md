# bit_shift_left



Shifts the binary representation of a numeric expression to the left by a specified number of bits.

This function performs an **arithmetic left shift**, during which the bit length does not change, 0 is appended to the end, and the high bit remains unchanged. For example, shifting `10101` to the left by one bit results in `11010`.

{/* AUTOGENERATED_START:syntax */}
## Syntax

```sql
bit_shift_left(value, shift)
```

{/* AUTOGENERATED_END:syntax */}

{/* AUTOGENERATED_START:parameters */}
## Parameters

- `value` (`TINYINT`, `SMALLINT`, `INT`, `BIGINT`, `LARGEINT`): The value or numeric expression to shift.
- `shift` (`BIGINT`): The number of bits to shift.

{/* AUTOGENERATED_END:parameters */}

{/* AUTOGENERATED_START:returns */}
## Return value

The shifted value.

Type: Same as `value`

{/* AUTOGENERATED_END:returns */}

{/* AUTOGENERATED_START:usage */}
## Usage notes

- If any input parameter is NULL, NULL is returned.
- If `shift` is less than 0, 0 is returned.
- Shifting a `value` by `0` always results in the original `value`.
- Shifting `0` by a `shift` always results in `0`.
- If the data type of `value` is numeric but not an integer, that value is cast to an integer.
- If the data type of `value` is a string, the value is cast to an integer if possible. For example, the string "2.3" is cast to 2. If the value cannot be cast to an integer, it is treated as NULL.

{/* AUTOGENERATED_END:usage */}

{/* AUTOGENERATED_START:examples */}
## Examples

Shift an integer.

```sql
SELECT bit_shift_left(2, 1);
```

```plaintext
+----------------------+
| bit_shift_left(2, 1) |
+----------------------+
|                    4 |
+----------------------+
```

A non-integer numeric value is cast to an integer first.

```sql
SELECT bit_shift_left(2.2, 1);
```

```plaintext
+------------------------+
| bit_shift_left(2.2, 1) |
+------------------------+
|                      4 |
+------------------------+
```

A string is cast to an integer if possible.

```sql
SELECT bit_shift_left("2", 1);
```

```plaintext
+------------------------+
| bit_shift_left('2', 1) |
+------------------------+
|                      4 |
+------------------------+
```

The high bit is unchanged, so the sign is preserved.

```sql
SELECT bit_shift_left(-2, 1);
```

```plaintext
+-----------------------+
| bit_shift_left(-2, 1) |
+-----------------------+
|                    -4 |
+-----------------------+
```

{/* AUTOGENERATED_END:examples */}
