# bitxor



Returns the bitwise XOR of two numeric expressions.

{/* AUTOGENERATED_START:syntax */}
## Syntax

```sql
bitxor(x, y)
```

{/* AUTOGENERATED_END:syntax */}

{/* AUTOGENERATED_START:parameters */}
## Parameters

- `x` (`TINYINT`, `SMALLINT`, `INT`, `BIGINT`, `LARGEINT`): The left operand.
- `y` (`TINYINT`, `SMALLINT`, `INT`, `BIGINT`, `LARGEINT`): The right operand.

> `x` and `y` must agree in data type.

{/* AUTOGENERATED_END:parameters */}

{/* AUTOGENERATED_START:returns */}
## Return value

The bitwise XOR of `x` and `y`. If either argument is NULL, the result is NULL.

Type: Same as `x`

{/* AUTOGENERATED_END:returns */}

{/* AUTOGENERATED_START:examples */}
## Examples

```sql
SELECT bitxor(3, 0);
```

```plaintext
+--------------+
| bitxor(3, 0) |
+--------------+
|            3 |
+--------------+
```

{/* AUTOGENERATED_END:examples */}
