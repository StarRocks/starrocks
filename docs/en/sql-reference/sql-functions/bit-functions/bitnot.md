# bitnot



Returns the bitwise negation of a numeric expression.

{/* AUTOGENERATED_START:syntax */}
## Syntax

```sql
bitnot(x)
```

{/* AUTOGENERATED_END:syntax */}

{/* AUTOGENERATED_START:parameters */}
## Parameters

- `x` (`TINYINT`, `SMALLINT`, `INT`, `BIGINT`, `LARGEINT`): The value to negate.

{/* AUTOGENERATED_END:parameters */}

{/* AUTOGENERATED_START:returns */}
## Return value

The bitwise negation of `x`. If `x` is NULL, the result is NULL.

Type: Same as `x`

{/* AUTOGENERATED_END:returns */}

{/* AUTOGENERATED_START:examples */}
## Examples

```sql
SELECT bitnot(3);
```

```plaintext
+-----------+
| bitnot(3) |
+-----------+
|        -4 |
+-----------+
```

{/* AUTOGENERATED_END:examples */}
