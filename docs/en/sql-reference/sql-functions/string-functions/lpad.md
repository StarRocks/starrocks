# lpad



This function returns strings with a length of `len` (starting counting from the first syllable) in `str`. If `len` is longer than `str`, the return value is lengthened to `len` characters by adding pad characters in front of `str`.  If `str` is longer than `len`, the return value is shortened to `len` characters. `len` means the length of characters, not bytes.

{/* AUTOGENERATED_START:syntax */}
## Syntax

```sql
lpad(str, len [, pad])
```

{/* AUTOGENERATED_END:syntax */}

{/* AUTOGENERATED_START:parameters */}
## Parameters

- `str` (`VARCHAR`): The string to pad.
- `len` (`INT`): The length of the return value, measured in characters rather than bytes.
- `pad` (`VARCHAR`): Optional. The characters to add in front of `str`. Defaults to spaces.

{/* AUTOGENERATED_END:parameters */}

{/* AUTOGENERATED_START:returns */}
## Return value

A string of length `len`. If `len` is greater than the length of `str`, `pad` is repeated in front of `str` until the result is `len` characters long. If `len` is less than the length of `str`, the result is truncated to `len` characters.

Type: `VARCHAR`

{/* AUTOGENERATED_END:returns */}

{/* AUTOGENERATED_START:examples */}
## Examples

Pad a string up to the requested length.

```sql
SELECT lpad("hi", 5, "xy");
```

```plaintext
+---------------------+
| lpad('hi', 5, 'xy') |
+---------------------+
| xyxhi               |
+---------------------+
```

A length shorter than the string truncates it.

```sql
SELECT lpad("hi", 1, "xy");
```

```plaintext
+---------------------+
| lpad('hi', 1, 'xy') |
+---------------------+
| h                   |
+---------------------+
```

Without `pad`, spaces are used.

```sql
SELECT lpad("hi", 5);
```

```plaintext
+--------------------+
| lpad('hi', 5, ' ') |
+--------------------+
|    hi              |
+--------------------+
```

{/* AUTOGENERATED_END:examples */}
