# concat



This function combines multiple strings. If any of the parameter value is NULL, it will return NULL.

{/* AUTOGENERATED_START:syntax */}
## Syntax

```sql
concat(str, ...)
```

{/* AUTOGENERATED_END:syntax */}

{/* AUTOGENERATED_START:parameters */}
## Parameters

- `str` (`VARCHAR`): The strings to concatenate. This function accepts a variable number of arguments.

{/* AUTOGENERATED_END:parameters */}

{/* AUTOGENERATED_START:returns */}
## Return value

The concatenated string. If any argument is NULL, the result is NULL.

Type: `VARCHAR`

{/* AUTOGENERATED_END:returns */}

{/* AUTOGENERATED_START:examples */}
## Examples

Concatenate two strings.

```sql
SELECT concat("a", "b");
```

```plaintext
+------------------+
| concat('a', 'b') |
+------------------+
| ab               |
+------------------+
```

Concatenate three strings.

```sql
SELECT concat("a", "b", "c");
```

```plaintext
+-----------------------+
| concat('a', 'b', 'c') |
+-----------------------+
| abc                   |
+-----------------------+
```

A NULL argument makes the whole result NULL.

```sql
SELECT concat("a", null, "c");
```

```plaintext
+------------------------+
| concat('a', NULL, 'c') |
+------------------------+
| NULL                   |
+------------------------+
```

{/* AUTOGENERATED_END:examples */}

## keyword

CONCAT
