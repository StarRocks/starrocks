# reverse



Reverses a string or array. Returns a string or array with the characters in the string or array elements in reverse order.

{/* AUTOGENERATED_START:syntax */}
## Syntax

```sql
reverse(param)
```

{/* AUTOGENERATED_END:syntax */}

{/* AUTOGENERATED_START:parameters */}
## Parameters

- `param` (`VARCHAR`, `CHAR`, `ARRAY`): The string or array to reverse.

Only one-dimensional arrays are supported, and array elements cannot be of the DECIMAL type. The supported array element types are BOOLEAN, TINYINT, SMALLINT, INT, BIGINT, LARGEINT, FLOAT, DOUBLE, VARCHAR, DECIMALV2, DATETIME, DATE, and JSON. **JSON is supported from 2.5.**

{/* AUTOGENERATED_END:parameters */}

{/* AUTOGENERATED_START:returns */}
## Return value

The characters of the string, or the elements of the array, in reverse order.

Type: Same as `param`

{/* AUTOGENERATED_END:returns */}

{/* AUTOGENERATED_START:examples */}
## Examples

Reverse a string.

```sql
SELECT reverse('hello');
```

```plaintext
+------------------+
| reverse('hello') |
+------------------+
| olleh            |
+------------------+
```

Reverse an array.

```sql
SELECT reverse([4, 1, 5, 8]);
```

```plaintext
+-----------------------+
| reverse([4, 1, 5, 8]) |
+-----------------------+
| [8,5,1,4]             |
+-----------------------+
```

{/* AUTOGENERATED_END:examples */}
