# split



This function splits a given string according to the separators, and returns the split parts in ARRAY.

{/* AUTOGENERATED_START:syntax */}
## Syntax

```sql
split(content, delimiter)
```

{/* AUTOGENERATED_END:syntax */}

{/* AUTOGENERATED_START:parameters */}
## Parameters

- `content` (`VARCHAR`): The string to split.
- `delimiter` (`VARCHAR`): The separator to split on.

{/* AUTOGENERATED_END:parameters */}

{/* AUTOGENERATED_START:returns */}
## Return value

The parts of `content`, in order.

Type: `ARRAY<VARCHAR>`

{/* AUTOGENERATED_END:returns */}

{/* AUTOGENERATED_START:examples */}
## Examples

Split on a single character.

```sql
SELECT split("a,b,c", ",");
```

```plaintext
+---------------------+
| split('a,b,c', ',') |
+---------------------+
| ["a","b","c"]       |
+---------------------+
```

Split on a multi-character delimiter.

```sql
SELECT split("a,b,c", ",b,");
```

```plaintext
+-----------------------+
| split('a,b,c', ',b,') |
+-----------------------+
| ["a","c"]             |
+-----------------------+
```

An empty delimiter splits into individual characters.

```sql
SELECT split("abc", "");
```

```plaintext
+------------------+
| split('abc', '') |
+------------------+
| ["a","b","c"]    |
+------------------+
```

{/* AUTOGENERATED_END:examples */}
