# lower



Converts all strings in an argument to lower-case.

## Syntax

```plaintext
INT lower(VARCHAR str)
```

## Examples

```Plain Text
MySQL > SELECT lower("AbC123");
+-----------------+
| lower('AbC123') |
+-----------------+
| abc123          |
+-----------------+
```

## keyword

LOWER
