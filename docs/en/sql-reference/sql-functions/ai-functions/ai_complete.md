# ai_complete

Generates text using a chat Provider. Pass a prompt alone or include one image or video for the model to interpret.

## Syntax

```sql
ai_complete(prompt[, provider[, model[, options]]])
ai_complete(prompt, file[, provider[, model[, options]]])
```

## Arguments

- `prompt`: A VARCHAR expression describing the task for the model. You can use a text column.
- `file`: A FILE expression supplying the image or video. See [FILE input support](ai_functions.mdx#file-input).
- `options`: An optional constant JSON object. See [JSON options](ai_functions.mdx#json-options).

For the types and default behavior of `provider` and `model`, see [Common calling rules](ai_functions.mdx#common-calling-rules).

## Return value

Returns the text generated by the model as `VARCHAR`.

## Examples

```sql
SELECT ai_complete('Explain what columnar storage is in one sentence.');

SELECT ai_complete(
    prompt => 'Write a slogan for a bookstore.',
    provider => 'support_chat',
    model => 'chat-model',
    options => json_object('temperature', 0.2)
);
```

The [vision chat example](ai_functions.mdx#vision-chat) creates `vision_chat` and uses it to describe an image. The same Model Studio Provider can also describe a video supplied by URL.

```sql
SELECT ai_complete(
    prompt => 'Describe what happens in this video.',
    file => to_file(named_struct(
        'uri', 'https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20250107/lbcemt/new+video.mp4'
    )),
    provider => 'vision_chat'
);
```
