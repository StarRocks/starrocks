# SHOW RESOURCES

## 説明

このステートメントは、ユーザーが使用する権限を持つリソースを表示するために使用されます。一般ユーザーは、自分が使用する権限を持つリソースのみを使用できますが、root または admin ユーザーはすべてのリソースを表示できます。

構文:

```sql
SHOW RESOURCES
```
