# h3GetFaces

指定したH3セルが交差する二十面体の面番号（0〜19）を返します。H3は二十面体からの心射図法を使用しており、ほとんどのセルは単一の面に完全に収まりますが、面境界付近のセルは2つ以上の面にまたがる場合があります。

## Syntax

```Haskell
ARRAY<INT> h3GetFaces(BIGINT h3index)
```

## パラメータ

- `h3index`: H3セルインデックス。サポートされるデータ型: BIGINT。

## 戻り値

セルが交差する二十面体の面番号（0〜19）の`ARRAY<INT>`を返します。引数がNULL、またはインデックスが有効なH3セルでない場合はNULLを返します。

## 例

```sql
SELECT h3GetFaces(599686042433355775);
+--------------------------------+
| h3GetFaces(599686042433355775) |
+--------------------------------+
| [7]                            |
+--------------------------------+
```

## キーワード

H3GETFACES,H3,SPATIAL
