# h3kRing

起点セルからグリッド距離k以内のすべてのH3セル（塗りつぶされたディスク）を返します。結果には起点セル自体が含まれ、順序なしの配列として返されます。

## Syntax

```Haskell
ARRAY<BIGINT> h3kRing(BIGINT h3index, INT k)
```

## パラメータ

- `h3index`: 起点H3セルインデックス。サポートされるデータ型: BIGINT。
- `k`: 最大グリッド距離。0以上の整数でなければなりません。サポートされるデータ型: INT。

## 戻り値

起点からグリッド距離k以内（起点含む）のH3セルインデックスの`ARRAY<BIGINT>`を返します。要素の順序は保証されません。いずれかの引数がNULL、または`h3index`が有効なH3セルインデックスでない場合はNULLを返します。

## 例

```sql
SELECT h3kRing(644325529233966508, 1);
+-----------------------------------------------------------------------------------------------+
| h3kRing(644325529233966508, 1)                                                                |
+-----------------------------------------------------------------------------------------------+
| [644325529233966354,644325529233966355,644325529233966497,644325529233966504,644325529233966508,644325529233966509,644325529233966510] |
+-----------------------------------------------------------------------------------------------+
```
