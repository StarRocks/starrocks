# h3ToParent

指定したH3インデックスの、指定した粗い解像度における親セルを返します。H3階層では、解像度rの各セルは解像度r-1のちょうど1つのセル（その親）に完全に含まれます。

## Syntax

```Haskell
BIGINT h3ToParent(BIGINT h3index, INT resolution)
```

## パラメータ

- `h3index`: H3セルインデックス。サポートされるデータ型: BIGINT。
- `resolution`: 対象の親解像度。`h3index`の解像度以下でなければなりません。サポートされるデータ型: INT。

## 戻り値

指定した解像度での親セルインデックスをBIGINTで返します。いずれかの引数がNULL、`resolution`がセルの解像度より大きい、または`h3index`が有効なH3セルインデックスでない場合はNULLを返します。

## 例

```sql
SELECT h3ToParent(599405990164561919, 3);
+-----------------------------------+
| h3ToParent(599405990164561919, 3) |
+-----------------------------------+
| 590398848891879423                |
+-----------------------------------+
```

## キーワード

H3TOPARENT,H3,SPATIAL
