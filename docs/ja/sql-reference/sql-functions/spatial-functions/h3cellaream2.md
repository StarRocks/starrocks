# h3CellAreaM2

特定のH3セルの正確な面積を平方メートル単位で返します。指定解像度の全セルの平均面積を返す`h3HexAreaM2`とは異なり、この関数は個々のセルの正確な測地面積を計算します。

## Syntax

```Haskell
DOUBLE h3CellAreaM2(BIGINT h3index)
```

## パラメータ

- `h3index`: H3セルインデックス。サポートされるデータ型: BIGINT。

## 戻り値

セルの正確な面積（平方メートル）をDOUBLEで返します。引数がNULL、またはインデックスが有効なH3セルでない場合はNULLを返します。

## 例

```sql
SELECT h3CellAreaM2(579205133326352383);
+-----------------------------------+
| h3CellAreaM2(579205133326352383)  |
+-----------------------------------+
| 4106166334463.9233                |
+-----------------------------------+
```

## キーワード

H3CELLAREAM2,H3,SPATIAL
