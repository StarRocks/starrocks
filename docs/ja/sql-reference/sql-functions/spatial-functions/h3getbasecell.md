# h3GetBaseCell

指定したH3セルインデックスの基底セル番号を返します。すべてのH3セルは122個の基底セル（番号0〜121）のいずれかに属し、これらがH3階層の解像度0層を構成します。

## Syntax

```Haskell
INT h3GetBaseCell(BIGINT h3index)
```

## パラメータ

- `h3index`: H3セルインデックス。サポートされるデータ型: BIGINT。

## 戻り値

基底セル番号を表す[0, 121]の範囲のINTを返します。引数がNULL、またはインデックスが有効なH3セルでない場合はNULLを返します。

## 例

```sql
SELECT h3GetBaseCell(612916788725809151);
+-----------------------------------+
| h3GetBaseCell(612916788725809151) |
+-----------------------------------+
|                                12 |
+-----------------------------------+
```

## キーワード

H3GETBASECELL,H3,SPATIAL
