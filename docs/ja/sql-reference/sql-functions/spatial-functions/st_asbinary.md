# ST_AsBinary, ST_AsWKB

ネイティブ `GEOMETRY` 値を正規化されたリトルエンディアン OGC Well-Known Binary (WKB) にシリアライズします。

## 構文

```Haskell
VARBINARY ST_AsBinary(GEOMETRY geo)
VARBINARY ST_AsWKB(GEOMETRY geo)
```

## キーワード

ST_ASBINARY,ST_ASWKB,ST,ASBINARY,ASWKB
