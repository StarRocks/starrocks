# h3CellAreaRads2

特定のH3セルの正確な面積をステラジアン（立体角の単位）で返します。これは単位球面に投影されたセルの測地面積です。

## Syntax

```Haskell
DOUBLE h3CellAreaRads2(BIGINT h3index)
```

## パラメータ

- `h3index`: H3セルインデックス。サポートされるデータ型: BIGINT。

## 戻り値

セルの正確な面積（ステラジアン）をDOUBLEで返します。引数がNULL、またはインデックスが有効なH3セルでない場合はNULLを返します。

## 例

```sql
SELECT h3CellAreaRads2(579205133326352383);
+--------------------------------------+
| h3CellAreaRads2(579205133326352383)  |
+--------------------------------------+
| 0.10116268528089567                  |
+--------------------------------------+
```

## キーワード

H3CELLAREARADS2,H3,SPATIAL
