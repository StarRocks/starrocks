# h3ToChildren

指定したH3インデックスの、指定した細かい解像度におけるすべての子セルを返します。各六角形は次の解像度レベルで7つの子セルを持ち、五角形は6つの子セルを持ちます。

## Syntax

```Haskell
ARRAY<BIGINT> h3ToChildren(BIGINT h3index, INT resolution)
```

## パラメータ

- `h3index`: H3セルインデックス。サポートされるデータ型: BIGINT。
- `resolution`: 対象の子解像度。`h3index`の解像度以上でなければなりません。サポートされるデータ型: INT。

## 戻り値

指定した解像度でのすべての子セルインデックスの`ARRAY<BIGINT>`を返します。いずれかの引数がNULL、`resolution`がセルの解像度より小さい、または`h3index`が有効なH3セルインデックスでない場合はNULLを返します。

## 例

```sql
SELECT h3ToChildren(599405990164561919, 6);
+------------------------------------------------------------------------------------------------------------+
| h3ToChildren(599405990164561919, 6)                                                                        |
+------------------------------------------------------------------------------------------------------------+
| [603909588852408319,603909588986626047,603909589120843775,603909589255061503,603909589389279231,603909589523496959,603909589657714687] |
+------------------------------------------------------------------------------------------------------------+
```

## キーワード

H3TOCHILDREN,H3,SPATIAL
