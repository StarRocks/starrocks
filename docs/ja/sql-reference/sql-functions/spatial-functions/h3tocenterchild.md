# h3ToCenterChild

指定したH3インデックスの、指定した細かい解像度における中心子セルを返します。各H3セルは次の細かい解像度で7つの子セルを持ち、この関数は親の中心に最も近い中心を持つ子セルを返します。

## Syntax

```Haskell
BIGINT h3ToCenterChild(BIGINT h3index, INT resolution)
```

## パラメータ

- `h3index`: H3セルインデックス。サポートされるデータ型: BIGINT。
- `resolution`: 対象の子解像度。`h3index`の解像度以上でなければなりません。サポートされるデータ型: INT。

## 戻り値

指定した解像度での中心子セルインデックスをBIGINTで返します。いずれかの引数がNULL、`resolution`がセルの解像度より小さい、または`h3index`が有効なH3セルインデックスでない場合はNULLを返します。

## 例

```sql
SELECT h3ToCenterChild(577023702256844799, 1);
+----------------------------------------+
| h3ToCenterChild(577023702256844799, 1) |
+----------------------------------------+
| 581496515558637567                     |
+----------------------------------------+
```

## キーワード
