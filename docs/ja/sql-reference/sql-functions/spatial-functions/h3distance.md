# h3Distance

2つのH3セル間のグリッド距離をセル数で返します。グリッド距離は一方のセルから他方のセルへ移動するのに必要な最小ステップ数です。両方のセルは同じ解像度でなければなりません。

## Syntax

```Haskell
BIGINT h3Distance(BIGINT start, BIGINT end)
```

## パラメータ

- `start`: 開始H3セルインデックス。サポートされるデータ型: BIGINT。
- `end`: 終了H3セルインデックス。サポートされるデータ型: BIGINT。

## 戻り値

2つのH3セル間のグリッド距離（セル数）をBIGINTで返します。いずれかの引数がNULL、セルが同じ解像度でない、または五角形によって接続されていない領域にあるために距離を計算できない場合はNULLを返します。

## 例

```sql
SELECT h3Distance(590080540275638271, 590103561300344831);
+----------------------------------------------------+
| h3Distance(590080540275638271, 590103561300344831) |
+----------------------------------------------------+
|                                                  7 |
+----------------------------------------------------+
```

## キーワード

H3DISTANCE,H3,SPATIAL
