# h3HexRing

起点セルからグリッド距離がちょうどkのセル（中空リング）を返します。塗りつぶされたディスクを返す`h3kRing`とは異なります。結果には起点やkより近いセルは含まれません。リングパスに五角形が含まれる場合、空の配列が返されるかエラーが発生する場合があります。

## Syntax

```Haskell
ARRAY<BIGINT> h3HexRing(BIGINT h3index, INT k)
```

## パラメータ

- `h3index`: 起点H3セルインデックス。サポートされるデータ型: BIGINT。
- `k`: リングの正確なグリッド距離。0以上の整数でなければなりません。サポートされるデータ型: INT。

## 戻り値

起点からグリッド距離がちょうどkのH3セルインデックスの`ARRAY<BIGINT>`を返します。いずれかの引数がNULL、または`h3index`が有効なH3セルインデックスでない場合はNULLを返します。五角形がリングの周回を塞いでいる場合は空の配列を返すかエラーが発生します。

## 例

```sql
SELECT h3HexRing(590080540275638271, 1);
+------------------------------------------------------------------------------------------------------------------+
| h3HexRing(590080540275638271, 1)                                                                                 |
+------------------------------------------------------------------------------------------------------------------+
| [590077447899185151,590077585338138623,590079509483487231,590080471556161535,590080677714591743,590080815153545215] |
+------------------------------------------------------------------------------------------------------------------+
```

## キーワード

H3HEXRING,H3,SPATIAL
