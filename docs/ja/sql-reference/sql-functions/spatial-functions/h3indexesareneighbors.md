# h3IndexesAreNeighbors

2つのH3セルインデックスが辺を共有している（直接のグリッド隣接）場合に1を返します。両方のセルは同じ解像度でなければなりません。

## Syntax

```Haskell
BOOLEAN h3IndexesAreNeighbors(BIGINT idx1, BIGINT idx2)
```

## パラメータ

- `idx1`: 1つ目のH3セルインデックス。サポートされるデータ型: BIGINT。
- `idx2`: 2つ目のH3セルインデックス。サポートされるデータ型: BIGINT。

## 戻り値

2つのセルが辺を共有している場合は1（true）、そうでない場合は0（false）を返します。いずれかの引数がNULL、または同じ解像度の有効なH3セルインデックスでない場合はNULLを返します。

## 例

```sql
SELECT h3IndexesAreNeighbors(617420388351344639, 617420388352655359);
+---------------------------------------------------------------+
| h3IndexesAreNeighbors(617420388351344639, 617420388352655359) |
+---------------------------------------------------------------+
|                                                             1 |
+---------------------------------------------------------------+
```

## キーワード

H3INDEXESARENEIGHBORS,H3,SPATIAL
