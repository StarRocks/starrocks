# h3Line

開始セルから終了セルまで（両端含む）のグリッドパスを形成する順序付きH3セルインデックスの配列を返します。パスは2つのセル間の最短グリッドルートに沿います。両方のセルは同じ解像度でなければなりません。

## Syntax

```Haskell
ARRAY<BIGINT> h3Line(BIGINT start, BIGINT end)
```

## パラメータ

- `start`: 開始H3セルインデックス。サポートされるデータ型: BIGINT。
- `end`: 終了H3セルインデックス。サポートされるデータ型: BIGINT。

## 戻り値

開始セルから終了セルまでの順序付きH3セルインデックスの`ARRAY<BIGINT>`を返します。配列の長さは`h3Distance(start, end) + 1`と等しくなります。いずれかの引数がNULL、セルが同じ解像度でない、または五角形がルートを塞いでいてパスを計算できない場合はNULLを返します。

## 例

```sql
SELECT h3Line(590080540275638271, 590103561300344831);
+----------------------------------------------------------------------------------------------+
| h3Line(590080540275638271, 590103561300344831)                                               |
+----------------------------------------------------------------------------------------------+
| [590080540275638271,590080471556161535,590080883873021951,590106516237844479,590104385934065663,590103630019821567,590103561300344831] |
+----------------------------------------------------------------------------------------------+
```

## キーワード

H3LINE,H3,SPATIAL
