# bitnot

数値式のビット単位の否定を返します。

{/* AUTOGENERATED_START:syntax */}
## 構文

```sql
bitnot(x)
```

{/* AUTOGENERATED_END:syntax */}

## パラメータ

`x`: この式は、TINYINT、SMALLINT、INT、BIGINT、LARGEINT のいずれかのデータ型に評価される必要があります。

## 戻り値

戻り値は `x` と同じ型です。いずれかの値が NULL の場合、結果は NULL です。

{/* AUTOGENERATED_START:examples */}
## 例

```sql
SELECT bitnot(3);
```

```plaintext
+-----------+
| bitnot(3) |
+-----------+
|        -4 |
+-----------+
```

{/* AUTOGENERATED_END:examples */}
