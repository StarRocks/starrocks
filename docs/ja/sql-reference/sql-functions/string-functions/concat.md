# concat

この関数は複数の文字列を結合します。パラメータの値が NULL の場合、NULL を返します。

{/* AUTOGENERATED_START:syntax */}
## 構文

```sql
concat(str, ...)
```

{/* AUTOGENERATED_END:syntax */}

{/* AUTOGENERATED_START:examples */}
## 例

```sql
SELECT concat("a", "b");
```

```plaintext
+------------------+
| concat('a', 'b') |
+------------------+
| ab               |
+------------------+
```

```sql
SELECT concat("a", "b", "c");
```

```plaintext
+-----------------------+
| concat('a', 'b', 'c') |
+-----------------------+
| abc                   |
+-----------------------+
```

```sql
SELECT concat("a", null, "c");
```

```plaintext
+------------------------+
| concat('a', NULL, 'c') |
+------------------------+
| NULL                   |
+------------------------+
```

{/* AUTOGENERATED_END:examples */}

## keyword

CONCAT
