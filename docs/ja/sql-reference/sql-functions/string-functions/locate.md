# locate

この関数は、文字列内の部分文字列の位置を見つけるために使用されます（1から数え始め、文字単位で測定します）。第3引数の pos が指定されている場合、pos より後の位置で substr を見つけ始めます。str が見つからない場合は、0 を返します。

{/* AUTOGENERATED_START:syntax */}
## 構文

```sql
locate(substr, str [, pos])
```

{/* AUTOGENERATED_END:syntax */}

{/* AUTOGENERATED_START:examples */}
## 例

```sql
SELECT locate('bar', 'foobarbar');
```

```plaintext
+----------------------------+
| locate('bar', 'foobarbar') |
+----------------------------+
|                          4 |
+----------------------------+
```

```sql
SELECT locate('xbar', 'foobar');
```

```plaintext
+--------------------------+
| locate('xbar', 'foobar') |
+--------------------------+
|                        0 |
+--------------------------+
```

```sql
SELECT locate('bar', 'foobarbar', 5);
```

```plaintext
+-------------------------------+
| locate('bar', 'foobarbar', 5) |
+-------------------------------+
|                             7 |
+-------------------------------+
```

{/* AUTOGENERATED_END:examples */}

## keyword

LOCATE
