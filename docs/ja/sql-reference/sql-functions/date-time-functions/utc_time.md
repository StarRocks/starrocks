# utc_time

現在の UTC 時刻を 'HH:MM:SS' の形式で返します。

## 構文

```plaintext
TIME UTC_TIME()
```

## 例

```Plain Text
MySQL > select utc_time();
+----------------+
| utc_time()     |
+----------------+
| 12:31:18       |
+----------------+
```

## キーワード

UTC_TIME,UTC,TIME
