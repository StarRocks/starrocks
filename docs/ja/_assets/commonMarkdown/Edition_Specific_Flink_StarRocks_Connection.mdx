StarRocks の接続オプションには FE のアドレスを設定します。

- `jdbc-url`: `jdbc:mysql://<fe_host>:<fe_query_port>`。クエリポートのデフォルトは `9030` です。
- `load-url`: `<fe_host>:<fe_http_port>`。HTTP ポートのデフォルトは `8030` です。

`<fe_host>` には、FE の IP アドレスではなく、FE が再起動または置き換えられても変わらないアドレス（DNS 名や FE の前段にあるロードバランサーなど）を使用してください。そのアドレスが FE を指さなくなると、Flink ジョブはデータをロードできなくなります。

FE は各ロードリクエストを BE または CN にリダイレクトするため、Flink TaskManager からこれらの FE ポートに加えて、すべての BE または CN の HTTP ポート（デフォルトは `8040`）に接続できる必要があります。
