## VARCHAR 型の最大長はどれくらいで、長さがクエリパフォーマンスにどのように影響しますか？

VARCHAR 型の最大長は 1048576 バイトです。VARCHAR は可変長のデータ型であり、データサイズは実際の長さに基づき、メモリは定義された長さに基づいて事前に割り当てられることはありません。そのため、テーブル作成時に同じデータに対して異なる VARCHAR の長さを指定しても、クエリパフォーマンスへの影響はほとんどありません。STRING 型は VARCHAR(65533) と同等です。
