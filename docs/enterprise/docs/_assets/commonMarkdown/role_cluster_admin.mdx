## `cluster_admin`

`cluster_admin` is the built-in cluster administrator.

- Focused on management of cluster infrastructure
- Granted with privileges on node and warehouse management
- Immutable role

Privilege scope:

| Privilege Level   | Privilege Item |
| ----------------- | -------------- |
| SYSTEM            | <ul><li>NODE</li><li>CREATE WAREHOUSE</li></ul> |
| WAREHOUSE         | <ul><li>USAGE</li><li>DROP</li><li>ALTER</li></ul> |
