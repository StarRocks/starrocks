
## Manual cluster snapshot

From v4.0 onwards, you can manually create cluster snapshots to allow recovery at a specific point in time.

Use the following statement to manually create a cluster snapshot:

Syntax:

```SQL
CREATE CLUSTER SNAPSHOT [IF NOT EXISTS] <snapshot_name>
[COMMENT 'comment']
[STORAGE VOLUME <storage_volume_name>]
```

Parameter:

- `snapshot_name`: The name of the snapshot to create.
- `COMMENT`: The description for snapshot.
- `storage_volume_name`: Specifies the storage volume used to store the snapshot. If this parameter is not specified, the default storage volume will be used. For details on creating a storage volume, see [CREATE STORAGE VOLUME](../../sql-reference/sql-statements/cluster-management/storage_volume/CREATE_STORAGE_VOLUME.md).
