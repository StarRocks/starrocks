Syntax:

```SQL
ADMIN SET AUTOMATED CLUSTER SNAPSHOT ON
[STORAGE VOLUME <storage_volume_name>]
[PROPERTIES ("key"="value", ...)]
```

Parameters:

- `storage_volume_name`: Specifies the storage volume used to store the snapshot. If this parameter is not specified, the default storage volume will be used. For details on creating a storage volume, see [CREATE STORAGE VOLUME](../sql-reference/sql-statements/cluster-management/storage_volume/CREATE_STORAGE_VOLUME.md).

- Properties (Supported from v4.1 onwards):

  - `snapshot_scope`: Specifies the scope of the snapshot. Valid values: `local` (Default) and `external`. To enable cross-region disaster recovery, set this property to `external`. If this property is not set or set to `local`, the snapshot can only be used for recovery within the region.
  - `warehouse`: Specifies the warehouse used to create the snapshot. If this property is not specified, `default_warehouse` is used.
