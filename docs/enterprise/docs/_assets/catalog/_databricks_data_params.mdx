
:::note
From v4.0 onwards, Databricks Unity Catalogs support Vended Credentials. Vended Credential is enabled by default. You only need to specify `aws.s3.region` in `StorageCredentialParams` for accessing data stored in AWS S3. For Azure Blob Storage, Azure Data Lake Storage Gen2, and Google Cloud Storage, you do not need to specify `StorageCredentialParams`. For example usages, see [Databricks Unity Catalog](../../data_source/catalog//databricks_unity_catalog.md).
:::
