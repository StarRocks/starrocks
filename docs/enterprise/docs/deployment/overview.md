# Deployment overview

These are the steps involved in deplying CelerData Enterprise:

1. Chosse an [architecture](../introduction/Architecture.md)
1. Calculate your initial [database size](./15_plan_cluster.md)
1. Deploy your virtual machines and install [CelerData Manager](./10_install_prep.md)
1. Configure the database nodes for [shared-nothing](./30_shared_nothing.md) or [shared-data](./30_shared_data.md)
