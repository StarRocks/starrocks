# Deployment overview

These are the steps involved in deplying CelerData Enterprise:

1. Choose an [architecture](../introduction/Architecture.md)
2. Calculate your initial [database size](./15_plan_cluster.md)
3. Deploy your virtual machines and install [CelerData Manager](./10_install_prep.md)
4. Configure the database nodes for [shared-nothing](./30_shared_nothing.md) or [shared-data](./30_shared_data.md)
5. [License Your CelerData Cluster using RESTful API](./40_license_cluster.md)
