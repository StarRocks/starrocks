# Quick Start

The guides in this folder are written for people new to CelerData Enterprise Edition and deploying services with Helm and
Kubernetes operators.

If you are an expert in these topics, then you may want to grab the `values.yaml` file from the [documentation samples](https://github.com/StarRocks/demo/tree/master/documentation-samples/enterprise-edition/operator) and get going. For a step by step experience, please start with the [Basic Quick Start](./basic.md).

To manage database authentication and authorization with LDAP and database roles, read the [LDAP guide](./LDAP.md).
