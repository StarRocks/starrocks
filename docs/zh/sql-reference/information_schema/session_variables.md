# session_variables

`session_variables` 提供有关 Session 变量的信息。

`session_variables` 提供以下字段：

| **字段**       | **描述**             |
| -------------- | -------------------- |
| VARIABLE_NAME  | Session 变量的名称。 |
| VARIABLE_VALUE | Session 变量的值。   |
