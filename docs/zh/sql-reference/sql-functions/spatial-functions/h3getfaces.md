# h3GetFaces

返回给定 H3 单元所相交的二十面体面编号（0–19）。H3 使用从二十面体到球面的球心投影；大多数单元完全位于单个面上，但靠近面边界的单元可能跨越两个或多个面。

## 语法

```Haskell
ARRAY<INT> h3GetFaces(BIGINT h3index)
```

## 参数说明

- `h3index`：H3 单元索引。支持的数据类型为 BIGINT。

## 返回值说明

返回 `ARRAY<INT>` 类型，包含该单元相交的二十面体面编号（0–19）。如果参数为 NULL 或不是有效的 H3 单元索引，则返回 NULL。

## 示例

```sql
SELECT h3GetFaces(599686042433355775);
+--------------------------------+
| h3GetFaces(599686042433355775) |
+--------------------------------+
| [7]                            |
+--------------------------------+
```
