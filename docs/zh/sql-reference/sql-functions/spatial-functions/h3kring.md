# h3kRing

返回与原点单元网格距离在 k 以内的所有 H3 单元（填充圆盘）。结果包含原点单元本身，以无序数组形式返回。

## 语法

```Haskell
ARRAY<BIGINT> h3kRing(BIGINT h3index, INT k)
```

## 参数说明

- `h3index`：原点 H3 单元索引。支持的数据类型为 BIGINT。
- `k`：最大网格距离，必须为非负整数。支持的数据类型为 INT。

## 返回值说明

返回 `ARRAY<BIGINT>` 类型，包含与原点网格距离不超过 k 的所有 H3 单元索引（含原点）。元素顺序不保证。如果任意参数为 NULL 或 `h3index` 不是有效的 H3 单元索引，则返回 NULL。

## 示例

```sql
SELECT h3kRing(644325529233966508, 1);
+-----------------------------------------------------------------------------------------------+
| h3kRing(644325529233966508, 1)                                                                |
+-----------------------------------------------------------------------------------------------+
| [644325529233966354,644325529233966355,644325529233966497,644325529233966504,644325529233966508,644325529233966509,644325529233966510] |
+-----------------------------------------------------------------------------------------------+
```
