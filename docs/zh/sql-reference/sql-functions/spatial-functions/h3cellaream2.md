# h3CellAreaM2

返回指定 H3 单元的精确面积（以平方米为单位）。与返回给定精度级别所有单元平均面积的 `h3HexAreaM2` 不同，此函数计算该单元的精确测地面积。

## 语法

```Haskell
DOUBLE h3CellAreaM2(BIGINT h3index)
```

## 参数说明

- `h3index`：H3 单元索引。支持的数据类型为 BIGINT。

## 返回值说明

返回 DOUBLE 类型，表示该单元的精确面积（平方米）。如果参数为 NULL 或不是有效的 H3 单元索引，则返回 NULL。

## 示例

```sql
SELECT h3CellAreaM2(579205133326352383);
+-----------------------------------+
| h3CellAreaM2(579205133326352383)  |
+-----------------------------------+
| 4106166334463.9233                |
+-----------------------------------+
```
