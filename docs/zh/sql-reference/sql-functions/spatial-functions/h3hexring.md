# h3HexRing

返回与原点单元网格距离恰好为 k 的所有单元（空心环状），与返回填充圆盘的 `h3kRing` 不同。结果不包含原点或距离小于 k 的单元。如果沿环路径遇到五边形，可能返回空数组或报错。

## 语法

```Haskell
ARRAY<BIGINT> h3HexRing(BIGINT h3index, INT k)
```

## 参数说明

- `h3index`：原点 H3 单元索引。支持的数据类型为 BIGINT。
- `k`：环的精确网格距离，必须为非负整数。支持的数据类型为 INT。

## 返回值说明

返回 `ARRAY<BIGINT>` 类型，包含与原点网格距离恰好为 k 的所有 H3 单元索引。如果任意参数为 NULL 或 `h3index` 不是有效的 H3 单元索引，则返回 NULL。如果五边形阻断环遍历，则返回空数组或报错。

## 示例

```sql
SELECT h3HexRing(590080540275638271, 1);
+------------------------------------------------------------------------------------------------------------------+
| h3HexRing(590080540275638271, 1)                                                                                 |
+------------------------------------------------------------------------------------------------------------------+
| [590077447899185151,590077585338138623,590079509483487231,590080471556161535,590080677714591743,590080815153545215] |
+------------------------------------------------------------------------------------------------------------------+
```
