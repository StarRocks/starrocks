# h3GetBaseCell

返回给定 H3 单元索引的基础单元编号。每个 H3 单元都属于 122 个基础单元之一（编号 0–121），这些基础单元构成 H3 层级体系的精度 0 层。

## 语法

```Haskell
INT h3GetBaseCell(BIGINT h3index)
```

## 参数说明

- `h3index`：H3 单元索引。支持的数据类型为 BIGINT。

## 返回值说明

返回 INT 类型，取值范围为 [0, 121]，表示基础单元编号。如果参数为 NULL 或不是有效的 H3 单元索引，则返回 NULL。

## 示例

```sql
SELECT h3GetBaseCell(612916788725809151);
+-----------------------------------+
| h3GetBaseCell(612916788725809151) |
+-----------------------------------+
|                                12 |
+-----------------------------------+
```
