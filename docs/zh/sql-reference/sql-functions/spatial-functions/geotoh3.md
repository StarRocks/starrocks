# geoToH3

将 WGS84 经纬度坐标点转换为指定精度的 H3 六边形网格单元索引，返回值为 BIGINT 类型的 64 位 H3 单元索引，与 ClickHouse、Snowflake 和 Databricks 的 H3 语义兼容。

## 语法

```Haskell
BIGINT geoToH3(DOUBLE lng, DOUBLE lat, INT resolution)
```

## 参数说明

- `lng`：点的经度，单位为度（WGS84）。支持的数据类型为 DOUBLE。
- `lat`：点的纬度，单位为度（WGS84）。支持的数据类型为 DOUBLE。
- `resolution`：H3 精度级别，取值范围为 [0, 15]。精度越高，单元越小越精确。支持的数据类型为 INT。

## 返回值说明

返回 BIGINT 类型的 H3 单元索引，表示包含给定坐标点的 H3 单元。如果任意参数为 NULL、坐标超出有效范围或精度不在 [0, 15] 范围内，则返回 NULL。

## 示例

示例一：获取旧金山某地点在精度 9 下的 H3 单元索引。

```sql
SELECT geoToH3(-122.4194, 37.7749, 9);
+--------------------------------+
| geoToH3(-122.4194, 37.7749, 9) |
+--------------------------------+
|          617700169958293503    |
+--------------------------------+
```

示例二：验证返回的索引是否有效，且精度与输入一致。

```sql
SELECT h3IsValid(geoToH3(-122.4194, 37.7749, 9)),
       h3GetResolution(geoToH3(-122.4194, 37.7749, 9));
+-------------------------------------------+--------------------------------------------------+
| h3IsValid(geoToH3(-122.4194, 37.7749, 9)) | h3GetResolution(geoToH3(-122.4194, 37.7749, 9)) |
+-------------------------------------------+--------------------------------------------------+
|                                         1 |                                                9 |
+-------------------------------------------+--------------------------------------------------+
```

示例三：精度超出范围时返回 NULL。

```sql
SELECT geoToH3(-122.4194, 37.7749, 16);
+---------------------------------+
| geoToH3(-122.4194, 37.7749, 16) |
+---------------------------------+
|                            NULL |
+---------------------------------+
```
