# geoToMGRS

将 WGS84（经度、纬度）坐标点编码为[军事格网参照系（MGRS）](https://en.wikipedia.org/wiki/Military_Grid_Reference_System)字符串。可选参数 `precision` 控制东向/北向数字的位数：默认值为 5（精度 1 米），最低为 0（仅显示 100 公里格网方格）。仅支持 UTM 范围内的纬度 [−80°, 84°]。

## 语法

```Haskell
VARCHAR geoToMGRS(DOUBLE longitude, DOUBLE latitude[, INT precision])
```

## 参数说明

- `longitude`：经度（度），范围 `[-180, 180]`。支持的数据类型为 DOUBLE。
- `latitude`：纬度（度），范围 `[-80, 84]`。支持的数据类型为 DOUBLE。
- `precision`：可选。东向/北向各自的数字位数，范围 `[0, 5]`，默认值为 `5`。支持的数据类型为 INT。

| precision | 精度    | 示例输出              |
|-----------|---------|----------------------|
| 5         | 1 米    | `31UDQ4825111935`    |
| 4         | 10 米   | `31UDQ48251193`      |
| 3         | 100 米  | `31UDQ482119`        |
| 2         | 1 公里  | `31UDQ4811`          |
| 1         | 10 公里 | `31UDQ41`            |
| 0         | 100 公里| `31UDQ`              |

## 返回值说明

返回 VARCHAR 类型的 MGRS 参考字符串。如果 `latitude` 超出 `[-80, 84]`、`longitude` 超出 `[-180, 180]`、`precision` 超出 `[0, 5]` 或任意参数为 NULL，则返回 NULL。

## 示例

示例一：以 1 米精度编码埃菲尔铁塔坐标。

```sql
SELECT geoToMGRS(2.294497, 48.858222);
+--------------------------------+
| geoToMGRS(2.294497, 48.858222) |
+--------------------------------+
| 31UDQ4825111935                |
+--------------------------------+
```

示例二：以 100 米精度编码。

```sql
SELECT geoToMGRS(2.294497, 48.858222, 3);
+-----------------------------------+
| geoToMGRS(2.294497, 48.858222, 3) |
+-----------------------------------+
| 31UDQ482119                       |
+-----------------------------------+
```
