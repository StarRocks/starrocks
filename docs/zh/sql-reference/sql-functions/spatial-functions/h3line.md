# h3Line

返回从起始单元到终止单元（含两端）的有序 H3 单元索引数组，形成一条网格路径。路径沿两个单元之间的最短网格路线延伸。两个单元必须处于相同精度级别。

## 语法

```Haskell
ARRAY<BIGINT> h3Line(BIGINT start, BIGINT end)
```

## 参数说明

- `start`：起始 H3 单元索引。支持的数据类型为 BIGINT。
- `end`：终止 H3 单元索引。支持的数据类型为 BIGINT。

## 返回值说明

返回 `ARRAY<BIGINT>` 类型，包含从起始单元到终止单元的有序 H3 单元索引，数组长度等于 `h3Distance(start, end) + 1`。如果任意参数为 NULL、两个单元不在相同精度级别，或因五边形阻断路径导致无法计算，则返回 NULL。

## 示例

```sql
SELECT h3Line(590080540275638271, 590103561300344831);
+----------------------------------------------------------------------------------------------+
| h3Line(590080540275638271, 590103561300344831)                                               |
+----------------------------------------------------------------------------------------------+
| [590080540275638271,590080471556161535,590080883873021951,590106516237844479,590104385934065663,590103630019821567,590103561300344831] |
+----------------------------------------------------------------------------------------------+
```
