# h3Distance

返回两个 H3 单元之间以单元数量衡量的网格距离。网格距离是从一个单元到另一个单元所需的最少步数。两个单元必须处于相同精度级别。

## 语法

```Haskell
BIGINT h3Distance(BIGINT start, BIGINT end)
```

## 参数说明

- `start`：起始 H3 单元索引。支持的数据类型为 BIGINT。
- `end`：终止 H3 单元索引。支持的数据类型为 BIGINT。

## 返回值说明

返回 BIGINT 类型，表示两个 H3 单元之间的网格距离（单元数）。如果任意参数为 NULL、两个单元不在相同精度级别，或因五边形阻断导致无法计算距离，则返回 NULL。

## 示例

```sql
SELECT h3Distance(590080540275638271, 590103561300344831);
+----------------------------------------------------+
| h3Distance(590080540275638271, 590103561300344831) |
+----------------------------------------------------+
|                                                  7 |
+----------------------------------------------------+
```
