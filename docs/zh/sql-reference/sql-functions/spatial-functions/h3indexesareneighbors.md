# h3IndexesAreNeighbors

如果两个给定的 H3 单元索引共享一条边（即直接相邻），则返回 1。两个单元必须处于相同精度级别。

## 语法

```Haskell
BOOLEAN h3IndexesAreNeighbors(BIGINT idx1, BIGINT idx2)
```

## 参数说明

- `idx1`：第一个 H3 单元索引。支持的数据类型为 BIGINT。
- `idx2`：第二个 H3 单元索引。支持的数据类型为 BIGINT。

## 返回值说明

如果两个单元共享一条边，则返回 1（true）；否则返回 0（false）。如果任意参数为 NULL，或不是相同精度级别的有效 H3 单元索引，则返回 NULL。

## 示例

```sql
SELECT h3IndexesAreNeighbors(617420388351344639, 617420388352655359);
+---------------------------------------------------------------+
| h3IndexesAreNeighbors(617420388351344639, 617420388352655359) |
+---------------------------------------------------------------+
|                                                             1 |
+---------------------------------------------------------------+
```
