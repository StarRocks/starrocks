# locate



返回 `substr` 在 `str` 中出现的位置（从 1 开始计数，按「字符」计算）。如果指定了第 3 个参数 `pos`，则从 `pos` 下标开始的字符串处开始查找 `substr` 第一次出现的位置，如果没有找到则返回 0。

{/* AUTOGENERATED_START:syntax */}
## 语法

```sql
locate(substr, str [, pos])
```

{/* AUTOGENERATED_END:syntax */}

## 参数说明

`substr`: 支持的数据类型为 VARCHAR。

`str`: 支持的数据类型为 VARCHAR。

`pos`: 可选参数，支持的数据类型为 INT。

## 返回值说明

返回值的数据类型为 INT。

{/* AUTOGENERATED_START:examples */}
## 示例

```sql
SELECT locate('bar', 'foobarbar');
```

```plaintext
+----------------------------+
| locate('bar', 'foobarbar') |
+----------------------------+
|                          4 |
+----------------------------+
```

```sql
SELECT locate('xbar', 'foobar');
```

```plaintext
+--------------------------+
| locate('xbar', 'foobar') |
+--------------------------+
|                        0 |
+--------------------------+
```

```sql
SELECT locate('bar', 'foobarbar', 5);
```

```plaintext
+-------------------------------+
| locate('bar', 'foobarbar', 5) |
+-------------------------------+
|                             7 |
+-------------------------------+
```

{/* AUTOGENERATED_END:examples */}
