# concat



将多个字符串连接起来。如果参数中任意一个值是 NULL，那么返回的结果为 NULL。

{/* AUTOGENERATED_START:syntax */}
## 语法

```sql
concat(str, ...)
```

{/* AUTOGENERATED_END:syntax */}

## 参数说明

`str`: 支持的数据类型为 VARCHAR。

## 返回值说明

返回值的数据类型为 VARCHAR。

{/* AUTOGENERATED_START:examples */}
## 示例

```sql
SELECT concat("a", "b");
```

```plaintext
+------------------+
| concat('a', 'b') |
+------------------+
| ab               |
+------------------+
```

```sql
SELECT concat("a", "b", "c");
```

```plaintext
+-----------------------+
| concat('a', 'b', 'c') |
+-----------------------+
| abc                   |
+-----------------------+
```

```sql
SELECT concat("a", null, "c");
```

```plaintext
+------------------------+
| concat('a', NULL, 'c') |
+------------------------+
| NULL                   |
+------------------------+
```

{/* AUTOGENERATED_END:examples */}
