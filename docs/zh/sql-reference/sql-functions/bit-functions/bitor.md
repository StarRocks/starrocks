# bitor



返回两个数值在按位进行 OR 运算后的结果。

{/* AUTOGENERATED_START:syntax */}
## 语法

```sql
bitor(x, y)
```

{/* AUTOGENERATED_END:syntax */}

## 参数说明

`x`: 支持的数据类型为 TINYINT、SMALLINT、INT、BIGINT、LARGEINT。

`y`: 支持的数据类型为 TINYINT、SMALLINT、INT、BIGINT、LARGEINT。

> 注：使用时 `x` 与 `y` 数据类型要相同。

## 返回值说明

返回值的数据类型与 `x` 类型一致。

{/* AUTOGENERATED_START:examples */}
## 示例

```sql
SELECT bitor(3, 0);
```

```plaintext
+-------------+
| bitor(3, 0) |
+-------------+
|           3 |
+-------------+
```

{/* AUTOGENERATED_END:examples */}
