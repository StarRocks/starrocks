# get_json_scalar

从 JSON 字符串中指定的 JSON 路径解析并获取标量值，并以 VARCHAR 类型返回。

:::tip
所有的 JSON 函数和操作符都列在导航栏和[概览页面](../overview-of-json-functions-and-operators.md)

通过[生成列](../../../sql-statements/generated_columns.md)加速查询
:::

如果 `json_str` 或 `json_path` 的格式无效，或者找不到匹配的内容，此函数将返回 NULL。如果 `json_path` 定位到的值是 JSON 对象或 JSON 数组，此函数也会返回 NULL，因为它只返回标量值（数字、字符串、布尔值和 JSON null）。

## 语法

```Haskell
VARCHAR get_json_scalar(VARCHAR json_str, VARCHAR json_path)
```

## 参数

- `json_str`：JSON 字符串。支持的数据类型是 VARCHAR。
- `json_path`：JSON 路径。支持的数据类型是 VARCHAR。
   
  - `json_path` 必须以 `$` 开头，并使用 `.` 作为路径分隔符。如果路径中包含 `.`，可以用一对 `"` 包围。
  - `[ ]` 用作数组下标，从 0 开始。

## 示例

1. 获取键为 "k1" 的值。该值为数字 `1`，返回 `1`。

    ```Plain Text
    MySQL > SELECT get_json_scalar('{"k1":1, "k2":"v2"}', "$.k1");
    +----------------------------------------------------+
    | get_json_scalar('{"k1":1, "k2":"v2"}', '$.k1')     |
    +----------------------------------------------------+
    | 1                                                  |
    +----------------------------------------------------+
    ```

2. 获取键为 "my.key" 的数组中的第二个元素。第二个元素为 `false`，返回 `false`。

    ```Plain Text
    MySQL > SELECT get_json_scalar('{"k1":"v1", "my.key":[true, false, 3]}', '$."my.key"[1]');
    +-----------------------------------------------------------------------------+
    | get_json_scalar('{"k1":"v1", "my.key":[true, false, 3]}', '$."my.key"[1]')  |
    +-----------------------------------------------------------------------------+
    | false                                                                       |
    +-----------------------------------------------------------------------------+
    ```

3. 获取路径为 `k1.key -> k2` 的数组中的第一个元素。第一个元素为 `false`，返回 `false`。

    ```Plain Text
    MySQL > SELECT get_json_scalar('{"k1.key":{"k2":[false, true]}}', '$."k1.key".k2[0]');
    +-------------------------------------------------------------------------+
    | get_json_scalar('{"k1.key":{"k2":[false, true]}}', '$."k1.key".k2[0]')  |
    +-------------------------------------------------------------------------+
    | false                                                                   |
    +-------------------------------------------------------------------------+
    ```

4. 获取键为 "k1" 的值，该值是一个 JSON 对象而不是标量值，返回 NULL。

    ```Plain Text
    MySQL > SELECT get_json_scalar('{"k1":{"k11":"v11"}}', '$.k1');
    +----------------------------------------------------+
    | get_json_scalar('{"k1":{"k11":"v11"}}', '$.k1')    |
    +----------------------------------------------------+
    | NULL                                               |
    +----------------------------------------------------+
    ```
